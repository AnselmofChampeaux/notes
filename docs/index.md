## 这个站点是怎么来的

- 内容以 Markdown 写在一个**私有**仓库里（那里是全量笔记）
- 挑出适合公开的部分，复制到这个**公开**仓库
- 由 GitHub Pages 自动构建成你正在看的这个网站

> 采用「私有库存全文，公库只放精华」的单向流动：
> **从私到公容易，从公到私不可能。**
