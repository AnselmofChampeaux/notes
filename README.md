# notes-public

> 公开笔记库 · 从私有知识库里**挑出来**的、对别人也可能有用的内容
> 这个仓库同时是网站源码：**https://anselmofchampeaux.github.io/notes/**

## 这里放什么

| 放 | 不放 |
|---|---|
| 技术踩坑与解决办法 | 私人日记、情绪记录 |
| 工具配置与命令速查 | 账号、密钥、内网地址 |
| 读书笔记与公开思考 | 别人的隐私、工作中的内部信息 |
| 学习路线与阶段性总结 | 未经证实的传闻 |

## 目录结构

```
docs\                 ← 网站源码（GitHub Pages 从这里发布）
  _config.yml         ← 网站配置（标题、主题）
  index.md            ← 网站首页
  notes\              ← 每篇笔记一个 .md 文件
```

## 怎么发一篇新笔记

1. 从私有知识库挑一篇已经写好的笔记
2. 复制到 `docs\notes\` 下，**文件名用英文**（URL 更干净），例如 `git-push-in-sandbox.md`
3. 删掉涉及隐私的路径、账号、内部信息
4. 在 `docs\index.md` 里加一行链接
5. 提交推送：

```powershell
git add -A
git commit -m "发布：xxx"
git push
```

推送后等 1～2 分钟，网站自动更新。

## 为什么不直接把私有库公开

因为**一旦公开就收不回来了**——搜索引擎、缓存、他人的 fork 都会留下副本。
所以采用「私有库存全文，公库只放挑选过的」这种单向流动：**从私到公容易，从公到私不可能**。
